<summary>
  <h2>👀 Overview</h2>
</summary>

<p>
  README Kit is a personal collection of reusable documentation assets and templates that I frequently use when writing GitHub READMEs.
</p>

<p>
  Instead of recreating the same introductions, callouts, badges, layouts, or visual assets for every project, this repository centralizes them in a single place where they can be copied, adapted, and maintained over time.
</p>

  role='presentation'
  src='https://raw.githubusercontent.com/Richard-Passos/readme-kit/9b17b6fa2fb567f76880adbfff92670166776c99/assets/dividers/cyber_badge.svg'

<summary>
  <h2>📂 Repository Structure</h2>
</summary>

```text
readme-kit/
├── assets/
│   └── ...
├── callouts.md
├── intro.md
├── plugin.md
└── README.md
```

<ul>
  <li>
    <b>assets/</b>: Images, icons, dividers and other reusable visual resources.
  </li>

  <li>
    <b>callouts.md</b>: Common GitHub callouts such as NOTE, TIP, IMPORTANT and WARNING.
  </li>

  <li>
    <b>intro.md</b>: Reusable introduction sections.
  </li>

  <li>
    <b>plugin.md</b>: Markdown snippets frequently used in Moodle plugin documentation.
  </li>

  <li>
    <b>README.md</b>: Documentation for this repository.
  </li>
</ul>

<summary>
  <h2>✨ Features</h2>
</summary>

<ul>
  <li>
    <b>Reusable Markdown snippets</b> for common documentation sections.
  </li>

  <li>
    <b>GitHub callouts</b> ready to copy and paste.
  </li>

  <li>
    <b>Documentation templates</b> used across multiple repositories.
  </li>

  <li>
    <b>Visual assets</b> including banners, section dividers, icons and badges.
  </li>

  <li>
    <b>Single source of truth</b> for documentation resources shared between projects.
  </li>
</ul>
